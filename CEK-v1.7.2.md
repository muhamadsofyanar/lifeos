# Daftar cek setelah deploy

Centang setelah memeriksa. Buat catatan percobaan, bukan mengubah catatan penting.

1. [ ] Versi: footer menampilkan LifeOS v1.7.2 setelah Ctrl+F5. Healthcheck Coolify sehat dan login bekerja.
2. [ ] Data lama: jumlah/catatan penting, proyek, tugas, goal dan sesi hafalan tetap ada. Rekaman lama masih bisa diputar.
3. [ ] Catatan baru: buat judul UJI NOTES, isi beberapa paragraf, folder IZINHUKUM dan tags klien, tindak-lanjut. Simpan dan reload; semua isian tetap ada.
4. [ ] Folder: pilih IZINHUKUM; hanya catatan di folder itu tampil. Pilih Tanpa folder untuk melihat catatan dengan folder kosong. Folder yang diketik baru muncul setelah catatan disimpan.
5. [ ] Tag: pilih tindak-lanjut atau klik tag pada kartu; hanya catatan dengan tag itu tampil. Folder dan tag bekerja bersama, bukan saling menggantikan.
6. [ ] Pencarian: dengan filter aktif, cari judul UJI NOTES. Ubah ke kata yang tidak ada; tampil pesan kosong. Reset filter menghapus pencarian, pilihan folder dan tag.
7. [ ] Baca: isi panjang terbuka lengkap. Kartu daftar hanya ringkasan dan tidak memiliki gulir isi sendiri. [[Judul catatan lain]] membuka catatan tujuan; tautan masuk muncul pada pembaca.
8. [ ] Edit: ubah folder/tag/isi, simpan dan reload. Nilai terbaru muncul, tidak membuat catatan ganda. Ekspor Markdown memuat isi lengkap.
9. [ ] HP: periksa pada lebar 360 dan 390 px atau HP nyata. Tombol Menu membuka seluruh navigasi termasuk Notes dan Settings; memilih halaman menutup menu. Toolbar dan tombol dapat disentuh. Tidak perlu menggeser seluruh halaman ke samping.
10. [ ] Form di HP: buka catatan baru dan edit. Judul, isi, folder, tag, Simpan dan Batal terjangkau dengan menggulir dialog, termasuk ketika keyboard terbuka. Coba orientasi portrait/landscape.
11. [ ] Tablet dan desktop: periksa 768 dan 1440 px. Pada lebar menengah kartu satu kolom; pada layar lebar dua kolom. Judul panjang tetap berada di kartu.
12. [ ] Regresi: buka Tasks, Projects, Calendar, Areas & Goals, Belajar LifeOS dan Settings. Di Sullamul Hifz, rentang Al-Qari’ah maksimal 11; pilihan hubungan rekaman tetap membedakan sesi/surah.
13. [ ] Hapus catatan UJI NOTES setelah selesai. Pastikan catatan asli tetap ada.

Jika gagal, kirim nomor cek, halaman, langkah yang dilakukan, hasil yang muncul dan screenshot. Jangan sertakan password atau data klien sensitif. Beri tahu apakah gagal di HP atau desktop, serta versi footer yang terlihat.
