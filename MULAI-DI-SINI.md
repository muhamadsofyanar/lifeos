# LifeOS v1.7 — paket gabungan

**Sudah pernah deploy? Ikuti UPDATE-v1.7.md saja.** Tidak perlu deploy versi 1.1, 1.2, 1.3 atau 1.4 dahulu. Panduan update versi lama adalah catatan historis.

Untuk instalasi baru, ikuti README.md. Gunakan Dockerfile dan seluruh folder static terbaru. Satu pengguna, satu container, volume `/data`, port 8000.

Setelah terpasang: **Panduan → Idea Planner → Goal → Jadwalkan proses → Today → Focus → Review.**

Untuk hafalan: **Sullamul Hifz → bagian yang sedang dipelajari → rekam/putar → catat sesi → evaluasi → jadwalkan murajaah.**

Paket ini mengurangi kebutuhan redeploy kecil, tetapi tetap memerlukan pemeriksaan di server/perangkatmu. Jangan mengubah data nyata secara massal sebelum memastikan backup dan fungsi dasar bekerja.

Untuk pengisian sekaligus: baca PANDUAN-IMPOR.md. Gunakan Impor Gabung, bukan Restore Backup, untuk paket isian/template.

Belum memahami tujuan dan tahapan? Buka Belajar LifeOS dan mulai pelajaran 1. Klinik SMART membantu memperjelas satu Goal yang dipilih.
